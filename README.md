# CV Studio
Buka `index.html` langsung di browser (tanpa server/build). Data tersimpan di localStorage. Cetak: tombol "Cetak / PDF" lalu pilih "Simpan sebagai PDF".

## Backup
Data disimpan di browser ini saja. Gunakan "Ekspor" (per CV atau semua) untuk membuat file JSON, dan "Impor CV (JSON)" untuk memulihkan. Impor selalu membuat salinan baru, tidak menimpa CV yang ada.
